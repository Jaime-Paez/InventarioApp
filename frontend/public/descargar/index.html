Kava para Android

Tablets Amazon Fire y Android

Descargar APK
  1. Toca Descargar APK y espera a que termine.
  2. Abre el archivo desde las notificaciones o desde Descargas.
  3. Si la tablet lo pide, permite instalar apps de fuentes desconocidas para el navegador (Silk) y vuelve atrás.
  4. Toca Instalar. La app se actualiza sola con cada cambio del sistema; solo hay que volver a descargarla si se pide.
